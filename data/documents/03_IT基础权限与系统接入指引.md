**版本**：v2.1  
**生效日期**：2026年1月1日  
**适用对象**：全体正式员工、外包人员及实习生  
**归口部门**：IT与基础设施运维部（IT Ops）

## 第一章 统一身份认证与VPN远程访问

### 1.1 统一员工账号（SSO）与密码策略
1. **账号格式**：入职时自动生成企业统一邮箱与 SSO 账号，格式为 `姓氏拼音+名字拼音@nebulalink.com`（如 `zhangsan@nebulalink.com`）。
2. **初始密码与重置**：入职首日通过手机短信接收初始随机密码，首次登录须立即强制修改。
3. **密码复杂度要求**：
   - 长度至少 10 位；
   - 须同时包含大写字母、小写字母、数字及特殊符号（如 `@#$%^&*`）；
   - 密码每 90 天强制轮换一次，且不可与前 3 次历史密码重复；
   - 连续输错密码 5 次将锁定账号 30 分钟，如需紧急解锁可联系 IT 服务台（工号：8008）。

### 1.2 VPN 远程访问权限申请与配置
企业 VPN（NebulaConnect VPN）用于在公司外部网络环境下安全访问内网系统（如内部 Wiki、GitLab、测试环境等）：
1. **申请资格**：
   - 全体正式员工、通过试用期的员工均具备申请资格；
   - 外包技术人员及实习生需由所在项目负责人作为责任人联合发起。
2. **申请流程与步骤**：
   - **步骤一：提交工单**。登录企业 IT 服务门户（`https://it-service.nebulalink.com`），点击进入「权限申请」->「VPN 远程接入权限」；
   - **步骤二：选择权限范围与填写理由**。选择需要访问的网络区域（常规研发网 / 办公网 / 运维网），并详述业务背景及使用期限；
   - **步骤三：审批流转**。工单自动流转至直属业务主管审批；如涉及运维网或核心数据库访问，需额外加签安全团队（SecOps）负责人；
   - **步骤四：自动开通与客户端配置**。主管审批通过后 15 分钟内，系统自动下发 VPN 访问授权及配置指引邮件。
3. **客户端安装与双因子认证（2FA/MFA）**：
   - 前往 IT 软件中心下载 `NebulaConnect-Client`（支持 macOS / Windows / Linux / iOS / Android）；
   - 打开客户端，服务器地址填入 `vpn.nebulalink.com:8443`；
   - 登录时输入统一 SSO 用户名与密码，并在手机端打开 Google Authenticator / 企业微信 TOTP 动态口令完成二次验证绑定；
   - **连接超时机制**：单次 VPN 连接最长保持 8 小时，无流量闲置超过 30 分钟将自动断开。

## 第二章 研发协同平台权限指引

### 2.1 代码仓库（GitLab）权限
- **默认权限**：新入职研发人员默认享有部门所属 Group 的 `Reporter`（只读）权限；
- **开发者权限（Developer/Maintainer）**：加入具体项目仓库需在 IT 服务台提交「GitLab 项目权限变更申请」，由该项目的 Repository Owner（主程序员/架构师）审批；
- **Master 分支保护**：所有核心业务仓库的 `main` / `master` / `release` 分支均受保护，严禁直接 Push 代码，必须通过 Merge Request（MR）且获得至少 1 位 Code Reviewer 批准后方可合并。

### 2.2 项目管理与知识库（Jira & Confluence）
- **Jira 权限**：新员工入职即自动开通 Jira 基础查看与任务流转权限，项目管理员可在各 Project Settings 内直接分配 Project Role；
- **Confluence 空间权限**：全员享有公司公共知识库（Company Wiki）阅读与评论权限；部门内部 Space 的编辑与管理权限由各部门 Confluence Admin 统一维护。

## 第三章 生产环境与云平台特权访问管理

### 3.1 生产环境（Prod）特权申请
- 生产环境服务器、Kubernetes 集群、生产数据库及云平台（AWS / 阿里云 / 腾讯云）控制台实行**最小权限原则（Least Privilege）**；
- 严禁开通长期生产 root 或 Admin 权限；
- 临时生产排障需申请「堡垒机临时访问工单（Jumpserver Token）」，最长有效期为 4 小时，由技术 VP 审批，且操作全过程开启屏幕录制与审计追踪。

### 3.2 离职与转岗权限回收
- 员工提交离职申请并在最后工作日（Last Day）18:00，HR 离职流程触发后，SSO 身份中心将自动一次性禁用所有内网系统、VPN 及企业邮箱访问；
- 内部转岗员工，原部门特有权限将在转岗生效日后 3 个工作日内自动收回，由新部门重新发起所需权限申请。
